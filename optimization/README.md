# Mobile app optimization — source of truth

Everything about ShelfTap's performance work lives here: docs, measurement method, before/after results, device profiles.

Course topics: 1 UI/graphics and 2 memory/resources (main), supported by 6 computation (offline full-text search), 7 performance + security, 3 scheduling/multithreading, 5 AI.

Targets, measured before and after every change on a low-cost device:

| Metric | Target |
|---|---|
| Offline search over 100k books | < 50 ms |
| Catalog scrolling with covers | 60 fps |
| Memory while browsing | < 150 MB |
| Self-checkout tap | < 1 s |
