# Ports: corpus code as the A variant (E2)

Rule (alpha, protocol A4, 2026-11-21): for each corpus-derived factor, candidates are campaign runs (not pilots) with a detector finding for the rule ID, ordered by run start time; take the **first** whose offending code ports with **mechanical changes only** (package, imports, data-source binding, reformatting, instrumentation probes; no change to the offending construct).
Candidate list: `e1-corpus/results/a_candidates.csv`. `make_ports.py` regenerates the generated ports and all `<factor>.diff` files (diff of the corpus file against the port). Rejections: `rejections.csv` (none; the P08 rank-1 crash check is `a10-crash-check/`).
