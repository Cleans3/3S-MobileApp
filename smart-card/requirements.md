# Smart card course: project requirements

The smart card course grades the project at three checkpoints. Each list is the minimum required at that checkpoint.

## Checkpoint 1: 2026-11-30

- Build the user interface of the desktop (PC) software.
- Write the overall idea of the problem, with a clear and detailed description of every function.
- PIN: create it, change it and verify it, with a limit on wrong attempts.
- Store information on the card.

## Checkpoint 2: 2026-12-14

- Store information on the card encrypted with AES (secret-key cryptography).
- Authenticate the card with RSA (public-key cryptography).

## Checkpoint 3: final graded report (expected 2026-12-28)

- Build the desktop software that talks to the card, backed by a database.
- Complete the project with every function described in the problem.
- Hand in a Word report and a PowerPoint deck for the presentation.
